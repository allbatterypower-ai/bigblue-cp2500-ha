# Reverse engineering notes

## Методика

Для кожного нового поля використовуємо контрольований стан CP2500:

1. На дисплеї станції фіксуються реальні значення.
2. В Home Assistant натискається **Upload BLE Snapshot to GitHub**.
3. У приватному log repository зберігається raw 236-byte frame.
4. Значення на дисплеї порівнюються з little-endian u16/s16 кандидатами у frame.
5. Мапінг вважається підтвердженим тільки після перевірки щонайменше у двох різних станах, якщо це можливо.

## Вже виконані контрольні тести

### AC Input

Перевірено приблизно при:
- 400 W
- 800 W

Підтверджено:
- Voltage offset 28 / 10
- Frequency offset 40 / 100
- Current offset 44 / 10
- Power offset 50

### DC Output

Перевірено:
- у стані 0 W
- при приблизно 40 W / 24 V / 1.6 A

Підтверджено:
- Voltage offset 74 / 10
- Current offset 76 / 10
- Power offset 78

## Принцип

Не додавати неперевірені поля в основні Home Assistant sensors лише тому, що raw value «схоже» на потрібне значення. Кандидати спочатку фіксуються тут або в аналізі snapshot-ів, а в інтеграцію переходять після контрольного тесту.
